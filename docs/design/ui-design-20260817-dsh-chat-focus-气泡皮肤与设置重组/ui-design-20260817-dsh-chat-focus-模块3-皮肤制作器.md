## 1. 模块概述

## 2. 工作台布局（单屏三区）

```text
┌────────────────────────────────────────────────┐
│ 皮肤制作器                                   ✕ │
├───────────────┬────────────────┬───────────────┤
│ ① 素材画布     │ ② 参数面板      │（②继续）       │
│ 画布区         │ 名称/适用侧     │ 帧率(fps)      │
│  九宫格参考线   │ 类型(自动/改判)  │ 循环/适配      │
│  安全区参考线   │ 切片 L/T/R/B    │ 文字建议色      │
│  缩放适应      │ 安全区 T/R/B/L  │ 遮罩建议值      │
├───────────────┴────────────────┴───────────────┤
│ ③ 实时预览：助手短文本 | 助手长文本 | 用户短文本     │
│    （M2 同组件渲染；序列帧动画播放中）              │
├────────────────────────────────────────────────┤
│ [打开皮肤包(.dshskin)] [重新选择素材]  [导出皮肤包] [取消] [保存皮肤] │
└────────────────────────────────────────────────┘
```

**编辑器级 zip 导入导出（决策 3.5，替换预设功能，总规划决策 #9）**：
- 「打开皮肤包」：选本地 .dshskin → M1 `openPackage(file)`（校验+解包，**零落盘**）→ 工作台回填素材/切片/参数全部可改；id 重新生成，保存即新皮肤（编辑分享包的标准入口，不经过皮肤库）；
- 「导出皮肤包」：当前草稿经 M1 `packSkin` 打包下载，**不写入皮肤库**；包内只含资产 + manifest，不含任何用户修改字段（数据分离原则，总规划 §5.1）；
- 该能力**替换** v0.2.4 的 6 套预设模板下拉（BUBBLE_PRESETS / focusBubblePreset 在正常模式隐藏、字段保留于 schema；OPFS 不可用时预设下拉降级回退显示——决策 #14，见 M6 §3）——「一键换外观」的入口由内置皮肤包承接（M1 §7）。

## 3. 素材导入与分析（②区联动）

接受三种输入（file picker + 拖拽投递）：
1. **单张 PNG**（含透明边）→ 判定 nine-patch；
2. **单张 GIF / APNG / 动态 WebP** → 判定 animated-image（解码探测帧数展示）；
3. **多选 PNG 序列**（≥2 张，按文件名自然排序）→ 判定 frame-sequence。

分析产出（导入后自动执行）：
- 尺寸/帧数/格式魔数校验（复用 M1 校验规则，超限当场报错不进工作台）；
- **切片建议**（决策 3.3）：扫描四边不透明像素包围盒，透明边厚度即建议 L/T/R/B；无透明边时建议值 = min(宽,高)/3 并提示「素材无透明边，已按三分之一给出建议」；
- **安全区建议**（动画路径）：= 切片建议值同源逻辑（九宫格语义迁移）；
- 文字建议色：包围盒主亮度（上四分位/下四分位均值）→ 建议深色图配浅字、浅色图配深字；仅作默认值建议，保存进 manifest 的 hint 字段（应用时 M4 提示，不强制）。
- **尾巴检测提示**（nine-patch）：扫描底边切片区疑似尾巴（底边不透明凸起超出两侧圆角包络）→ 画布高亮提示「检测到疑似气泡尾巴，请确保尾巴完整位于底边切片内，避免拉伸变形；追求零变形可置于角切片」（检测仅为提示，不强判）。

## 4. 画布交互（①区）

- 画布绘制内容：nine-patch/animated-image 画首帧（image 绘制）；frame-sequence 画第 1 帧 + 帧步进按钮（|◀ ◀ ▶ ▶|）逐帧核对；
- **九宫格参考线**：4 条双向半透明线（2 横 2 纵），拖拽移动，与右栏数字输入双向同步；线吸附 1px 网格；
- **安全区参考线**（动画类型）：矩形虚线框四边独立拖拽，标出内容安全区；
- 画布支持滚轮缩放 + 拖拽平移（大图标记）；参考线坐标始终显示为源图像素值；
- 键盘可访问性（WCAG 2.1 AA）：参考线选中后方向键 ±1px（Shift ±10px），等效于拖拽。

## 5. 保存与校验

- 保存前校验：名称非空（默认「未命名皮肤 YYYYMMDD」）；slices/safeArea ≥0 且互相不交叉（L<R、T<B）；frame-sequence 帧率 1–24；**尾巴约束**（nine-patch）：底边不透明凸起（疑似尾巴）超出底边切片范围时警告「尾巴跨越切片线，拉伸会变形」——警告可忽略保存（素材可能是异形设计），但默认聚焦到该参考线；
- 序列帧体积预估展示：帧数 × 单帧位图估算；>10MB 警告「建议减帧或降分辨率」（APNG 转码 stub 见总规划 §8）；
- 保存 = M1 `saveSkin`（编辑已有皮肤 = 覆盖同 id；「编辑副本」= 新 id）；
- 保存成功后 toast + 关闭工作台，M4 列表自动刷新（watchSkins）；
- 制作器拥有自己的预览部件（② 参数联动 + ③ 底部多尺寸实时预览，所见即所得），保存动作止于入库；是否将该皮肤应用到对话，由用户回到皮肤分组按 M4 决策 4.4 流程（应用 → 「预览 · 示例」→ 保存）自行完成，**不设「保存并试用」直达动作**（v1.1.0 修订）。

## 6. 失败场景（原则4）

| 场景 | 行为 |
|------|------|
| 素材解码失败/魔数不符 | 拒绝进入工作台，行内错误「不支持的图片格式」 |
| 序列帧尺寸不一致 | 警告并以首帧尺寸为准（预览标注「帧尺寸不一致」） |
| 保存时 OPFS 不可用/配额满 | 行内错误透传 M1 错误语义；工作台不关闭（草稿保留） |
| 打开的 .dshskin 校验失败 | 行内错误指出缺项（M1 §5 语义），工作台保持当前草稿不丢 |
| 导出皮肤包时资产仍在内存草稿中 | packSkin 直接读草稿 Blob，不依赖库；导出失败（磁盘/下载中断）toast 报错，草稿不受影响 |
| 参考线非法（交叉/越界） | 拖拽时钳制；数字输入非法值标红禁保存 |
