## 1. 模块概述

### 1.1 在系统组合中的位置

M6 是收官模块：设置页从「3 分组 + 两侧 16 字段内联展开」重组为「4 分组 + 气泡编辑弹窗 + 皮肤分组」，底部固定「预览 · 示例」保持。v1.1.0 起页面进入**两段式应用**（决策 6.5 / 总规划 #10）：一切呈现类编辑先写草稿缓存文件（M1 DraftStore）并只在「预览 · 示例」渲染，点「保存」才应用到对话。它不新增渲染功能，收纳 M3/M4/M5 的全部新入口，并清理 v0.2.x 沉淀的结构性问题（用户侧预览样式镜像——**已由 v0.2.5 统一管线解决**；locale 键族膨胀——仍待办）。

## 2. 重组后信息架构

```text
『对话显示』（单页滚动，草稿态编辑）
 ▾ 基本        插件总开关(即时生效) · 聊天气泡开关
 ▾ 折叠        保持展开回复数 N · 默认展开 · 折叠策略 · 思考收纳
 ▾ 气泡外观    气泡样式(标准/紧凑) · 摘要显示
 │   ├─ 助手气泡摘要行： [色块/渐变/皮肤缩略图] 皮肤名·主要状态 ●   [编辑…] [恢复默认]
 │   └─ 用户气泡摘要行： 同上                              [编辑…] [恢复默认]
 ▾ 皮肤        （M4 全部内容：当前皮肤两行 / 导入新建 / 卡片网格）
─────────────────────────────（固定底部，不随滚动）
 预览 · 示例：折叠框示例 + 助手气泡 + 用户气泡（M2 皮肤渲染 + M5 半透明生效）
 操作条：● 有未保存的更改 · 上次暂存 16:42    [放弃更改] [保存]   ← 决策 6.5
```

- 「编辑…」打开 Modal（约 640px 宽，可滚动）：BubbleSideEditor 字段（原 16 项去除废弃的预设下拉 = 15 项）+ M5 三滑杆 + 当前皮肤状态行（皮肤激活时背景类控件禁用并提示让位语义，链接引导到皮肤分组）；**OPFS 不可用时弹窗自动回退显示原 6 套预设下拉**（一键换外观降级，决策 #14，此时 preset 字段恢复读写、皮肤状态行置灰）；
- **弹窗内嵌镜像预览（决策 #13）**：Modal 遮罩 + 焦点陷阱会令页面底部的「预览 · 示例」不可见也不可点，故弹窗底部内嵌**只读迷你「预览 · 示例」镜像**——复用同一渲染组件与草稿快照，编辑写入草稿缓存后弹窗镜像与页面底部预览同步实时更新；**弹窗内不设独立保存按钮**，确认仍统一走页面底部操作条（单一确认点心智不变，决策 6.5）；
- **两段式应用（决策 6.5 / 总规划 #10）**：
  - 任一呈现类编辑（含 M4「应用到助手/用户」「清除」）先写入草稿缓存 draft.json（去抖 ~300ms），仅驱动「预览 · 示例」渲染；聊天流零变化；
  - 点击操作条「保存」→ 草稿全量**批量提交**设置域（按字段分组合并为最少次数的 scope 写入；宿主无批量 API 时在同一微任务内连续提交，成功/失败只提示一次，v1.3.0）→ 清除草稿缓存 → 对话经设置快照生效；「放弃更改」→ 清除缓存并回读已保存值渲染预览与摘要行；
  - 重新打开设置页时检出 draft.json → 自动恢复草稿态 + 横幅「已恢复上次未保存的更改」，避免误关页面丢失调整；皮肤基础上仍生效的参数（文字色/字体/遮罩/半透明等）在草稿中直接自定义并与所选皮肤合成预览；
  - 范围特例：「插件总开关」为功能开关保持即时生效不入草稿；其余字段统一两段式。
- 摘要行色块 = 12×12 圆角色块（纯色/渐变）或皮肤缩略图，按**草稿值**渲染并带未保存圆点标记，一眼判断当前状态。

## 4. 失败场景（原则4）

| 场景 | 行为 |
|------|------|
| 弹窗内某控件抛错 | 沿用现有行级错误边界思路：错误卡片替换该行，其余可用，可重试恢复 |
| 皮肤库不可用（OPFS） | 皮肤分组横幅+禁用（M4 §4），其余分组不受影响；两侧编辑弹窗回退显示预设下拉（决策 #14）；草稿缓存降级走 IndexedDB 持久层（M1 §8），两段式流程不中断 |
| 草稿缓存写入失败（配额/IO） | 页面工作副本与「预览 · 示例」照常（本就由工作副本驱动，不依赖缓存文件），后续编辑自动重试写入；一次性提示「更改暂存失败，刷新后未保存修改将丢失」（M1 §8） |
| 持久层完全不可用（OPFS 与 IndexedDB 均失败） | 不进入两段式：回落逐字段即时提交（即当前 v0.2.5 行为）+ 横幅说明；不以内存充当缓存文件（M1 §8） |
| 「保存」提交失败（设置域写异常） | 保持草稿态与操作条错误提示，草稿缓存不清除，可重试「保存」 |
| 恢复的草稿含未知字段/旧版本结构 | 按 `version` 前向兼容：未知键忽略、缺失键取 schema 默认；解析失败视为无草稿并清除（M1 §8） |
| 旧版本设置字段（v0.2.x） | 全部保留兼容——preset 字段按决策 #14 保留于 schema（正常模式无 UI 入口，降级模式恢复读写）；新增 6+2 字段走 schema 默认值；无迁移脚本 |

## 5. 无障碍与标准（原则6）

- 分组 details/summary 保持宿主语义结构；Modal 焦点陷阱与 Esc 关闭沿用宿主 Modal 原语；
- 滑杆/色块/缩略图均有 aria-label；键盘可完整操作（含 M3 参考线，见 M3 §4）；
- 文案 zh 全覆盖（locale 族化后逐一登记，不落英文键）。

## 6. 发版与验收

- 验收基准：重组后设置页**首屏（不滚动）可见四个分组标题与两侧气泡摘要行**；任意编辑操作滚动位置 ≤1 屏；「预览 · 示例」任何时刻可见；
- 两段式验收（决策 6.5）：任意编辑/选皮肤后、点击「保存」前，**聊天流零变化**；「保存」后对话立即反映；「放弃更改」精确回到已保存值（预览、摘要行、弹窗控件三处一致）；刷新/重开设置页草稿态完整恢复（含横幅提示）；未保存标识与操作条在任意滚动位置可达（固定底部）；
- 发版计划（全部待实施，决策 #11 合并发版）：M5（v0.3.0）→ M1–M4 + M6 + 两段式应用**合并为 v0.4.0**（含 draft.json、「预览 · 示例」操作条、弹窗镜像预览；README 截图更新；对应设计文档 v1.1.0–v1.3.0 修订）。
