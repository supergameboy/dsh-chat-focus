## 1. 模块概述

### 1.1 在系统组合中的位置

M5 在现有 CSS 变量注入链上新增三个正交维度：背景不透明度（rgba 合成）、毛玻璃（backdrop-filter）、整体不透明度（opacity）。改动的消费链：设置域新增 6 字段 → ChatFocusSection 两侧编辑器新增 3 滑杆（编辑期写草稿缓存，v1.1.0）→ custom 样式对象注入 ChatBubble（v0.2.5 双侧统一管线）→ 「预览 · 示例」编辑期实时反映草稿值；聊天流在「保存」提交草稿后生效（总规划决策 #10）。合成规则本身不变。**不引入新组件、不动 M1–M4**。

## 2. 新增设置字段（总规划 §5.1 已登记）

| 字段 | schema | 默认 | 语义 |
|------|--------|------|------|
| focusBubbleBgAlpha / focusUserBubbleBgAlpha | number 0–100 | 100 | 背景色不透明度；100=现状零变化（老设置兼容） |
| focusBubbleBlur / focusUserBubbleBlur | number 0–30 | 0 | 毛玻璃模糊半径 px；0=关闭 |
| focusBubbleOpacity / focusUserBubbleOpacity | number 10–100 | 100 | 气泡整体不透明度 %；下限 10 防完全消失找不到气泡 |

## 3. 合成规则（效果定义）

- **背景不透明度**：bg 字段值为空 → 不合成（主题默认色不参与 alpha，保持宿主一致性）；非空 → 解析（#hex / rgb() / rgba() / 关键字经 getComputedStyle 归一）→ 与 alpha 合成输出 `rgba(r,g,b,a)`；解析失败 → 原样透传 + 预览标「无法解析的背景色」；
- **毛玻璃**：blur>0 时 `.content` 追加 `backdrop-filter: blur(Npx) saturate(1.2)`（含 -webkit- 前缀）；作用在背景层之上、内容之下，与 overlay 遮罩共存（先毛玻璃后遮罩，视觉顺序：背景→毛玻璃→遮罩→文字）；
- **整体不透明度**：`.bubble` 容器 `opacity: N/100`；与 M2 皮肤层叠加时作用于皮肤之上（总规划 §5 / M2 §5 层序已定）；
- **双侧统一注入（v0.2.5 起，替代原「用户侧变量链」方案）**：助手侧与用户消息行走同一条 `<ChatBubble role>` 管线；alpha 合成在构造 custom 样式对象处完成（两侧共用一份逻辑）；blur/opacity 作为 `ChatBubbleCustomStyle` 新字段映射为 `--cf-bubble-blur` / `--cf-bubble-opacity`，分别在 `.content`（backdrop-filter）与 `.bubble`（opacity）消费——不再需要 `userBubbleVars` 或 `--cf-user-bubble-*` 独立变量链；
- **三控件与现有字段正交**：bgImage/渐变/overlay/皮肤激活均不影响三控件存在；皮肤激活时背景色让位为 transparent（L1-#8），此时背景不透明度滑杆禁用并提示「皮肤激活中，背景色已让位」。

## 4. 编辑器控件（进 M6 的气泡编辑弹窗）

- 三滑杆行：「背景不透明度」「毛玻璃模糊」「整体不透明度」，数值实时文本（`75%`、`8px`、`90%`）；
- 拖动 draft / 释放 commit——沿用 overlay 滑杆先例（本地 draft 驱动「预览 · 示例」，pointerup/keyup/blur 提交到**草稿缓存** M1 DraftStore，去抖持久化 draft.json；设置域仅在预览区操作条「保存」时随草稿整体提交——总规划决策 #10）；
- 毛玻璃滑杆仅在 CSS.supports 通过时渲染（决策 5.4）；
- 滑杆 aria-label + aria-valuetext（WCAG 2.1 AA）。

## 5. 可读性防护（WCAG，承接总规划 §7）

- 「预览 · 示例」对比度检查基于**草稿值**计算（所见即所算，决策 #10；可计算场景）：背景为纯色+已知 alpha、文字色已知 → 相对亮度对比度 < 4.5:1 时预览标 ⚠「对比度不足，文字可能难读」（正文本 4.5:1，大字 3:1 分级提示）；
- 不可计算场景（图片/渐变/皮肤背景）：毛玻璃或 alpha < 100 时显示一次性提示「透明背景下建议配合遮罩（蒙版）保证文字可读」；
- 检查只警示不阻止（用户主权）。

## 6. 失败场景（原则4）

| 场景 | 行为 |
|------|------|
| bg 色值无法解析（如手输错拼） | 原样透传（浏览器忽略非法值）+ 预览行内警示；不阻断其他字段 |
| backdrop-filter 不支持 | 滑杆隐藏；blur 字段值保留（升级浏览器后生效） |
| alpha/opacity 越界历史值 | schema min/max 钳制；UI 滑杆显示钳制后值 |
