## 3. 关键任务流程

### 3.1 T1 阅读对话流

```mermaid
flowchart TD
    S([打开会话]) --> L[组行渲染: 用户气泡 / 折叠框摘要+框外保留条 / 助手气泡]
    L --> F{折叠框存在?}
    F -->|是| R[回复气泡直接可见, 运行时信息压成一条摘要<br/>最近 N 条保留为框外可见行]
    F -->|否| N[全按宿主原序渲染]
    R --> E[底部跟随新回复]
```

- 反馈：无加载态；折叠框默认收起（foldDefaultOpen=false）；流式回复到达时底部跟随（宿主逻辑）；
- 框外保留条始终可见（M3 §2.2：不随折叠框状态变化）；
- 失败：设置不可用 → 按默认值渲染；节点缺失 → 跳过该行。

### 3.2 T2 展开/收起折叠框

```mermaid
stateDiagram-v2
    [*] --> collapsed
    collapsed --> partial: 点击「展开最近 N 条」
    collapsed --> expanded: 点击 summary
    partial --> expanded: 点击 summary
    partial --> collapsed: 点击收起
    expanded --> collapsed: 点击收起
    expanded --> partial: 点击收起至最近 N 条
```

- 反馈：展开动画 ≤200ms（宿主动效节奏）；流式追加不重置展开态；
- 持久化：localStorage 按组 anchorKey（L2-17）；
- 失败：组内单节点渲染错误 → JsonBlock fallback；localStorage 不可用 → 会话内生效。

### 3.3 T3 配置设置

```mermaid
flowchart TD
    S([打开设置]) --> G[侧边栏设置按钮]
    G --> P[『对话显示』section]
    P --> A{修改哪组?}
    A -->|基本| B[开关切换, 即时生效]
    A -->|折叠| C[参数调整, 即时生效]
    A -->|外观| D[样式调整 + 实时预览]
    B --> E[回到对话流验证]
    C --> E
    D --> E
```

- 反馈：写成功静默；写失败保留当前值，下轮订阅校正；namespace 不可用 → 页面只读降级提示；
- 即时性：所有控件变更不经保存按钮，直接 `settingsScope.set` + 订阅推送。

## 5. 异常与边缘场景（IA-L5）

| 场景 | 触发条件 | 处理 |
|------|---------|------|
| 极端长运行时组（>1000 节点） | 超长任务 | 虚拟列表常数级渲染（M4） |
| 流式更新与展开态冲突 | 展开中追加节点 | 追加可见，不重置滚动/状态 |
| 分页加载更早历史 | loadOlder | prepend 后组序列重算，锚点键保位 |
| 会话切换/刷新 | 视图重挂载 | 滚动位置恢复（宿主 chatScroll）、折叠态 localStorage 恢复 |
| 深色模式 | 主题切换 | 全部经宿主 token 自动跟随 |
