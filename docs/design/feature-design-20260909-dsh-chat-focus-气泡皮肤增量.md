## 3. 功能规格卡

### FEAT-101 气泡底纹不透明度

| 项 | 规格 |
|----|------|
| 输入 | 每侧一个 0~100 整数（默认 100），滑块 + 数字显示 |
| 输出 | 气泡底纹层（背景色/背景图片/渐变/遮罩）整体按该值合成透明度；文字与图标不受影响 |
| 边界 | 0 = 底纹完全不可见（文字仍可见）；100 = 现状；空/非法值回落 100 |
| 异常 | 值越界被夹取到 0~100；宿主 schema 校验失败时不落盘、界面保持旧值 |
| 验收 | 滑块拖到 40 时，气泡背景透出下方会话背景，文字对比度不变；刷新后保持 |

### FEAT-102 气泡毛玻璃

| 项 | 规格 |
|----|------|
| 输入 | 每侧一个预设选择：无 / 弱(4px) / 中(10px) / 强(18px) |
| 输出 | 底纹层应用 `backdrop-filter: blur(Npx) saturate(140%)` |
| 边界 | 「无」= 不输出该属性（零开销） |
| 异常 | 浏览器不支持 `backdrop-filter` 时静默降级为无模糊（不报错、不白屏） |
| 验收 | 选「中」后，气泡背后内容被模糊；DevTools 计算样式出现 backdrop-filter |

### FEAT-103 素材导入与格式识别

| 项 | 规格 |
|----|------|
| 输入 | 文件选择/拖拽：单张图片（png/jpg/webp/gif/apng/svg）、多个 PNG（序列帧）、视频（mp4 / webm） |
| 输出 | 素材描述：`{ kind: 'image' \| 'animated' \| 'sequence' \| 'video', 帧数, 尺寸, mime }` |
| 识别规则 | 多文件 → sequence；视频 MIME → video；单图按文件头判定动画（GIF 多帧 / APNG acTL / WebP ANIM）→ animated，否则 image |
| 边界 | 单文件 ≤ 16MB；序列帧 ≤ 60 张；无法解码 → 明确错误提示，不进入下一步 |
| 异常 | 解码失败/超限：向导停在当前步并显示原因，已选文件保留 |
| 验收 | 上传一张 GIF 显示「动画」徽标；上传 12 张 PNG 显示序列帧列表；上传 mp4 显示视频参数表单 |

### FEAT-104 视频抽帧 → 精灵图合成

| 项 | 规格 |
|----|------|
| 输入 | 视频文件 + 目标帧数（4~60，默认 24）+ 目标帧宽（120~480px，默认 320）+ 起点/时长（可选） |
| 输出 | 横向精灵图 PNG/JPEG（宽 = 帧数 × 帧宽，高 = 帧宽 × 视频宽高比）+ `{ frames, fps }` |
| 过程 | `<video>` + `seeked` 逐帧抽取到 canvas，分片 await 让出主线程；显示「第 i/N 帧」进度 |
| 边界 | 帧数上限 60（超过则降低采样）；精灵图长边 ≤ 16384px；超限自动降帧宽 |
| 异常 | 视频解码失败 / seek 超时（>5s）：中止并提示，不产生半成品皮肤 |
| 验收 | 3 秒 30fps 视频按 24 帧抽取，得到 24 帧精灵图，气泡内循环播放且无跳帧撕裂 |

### FEAT-105 PNG 序列帧合成精灵图

| 项 | 规格 |
|----|------|
| 输入 | 多个 PNG 文件（按文件名自然序排序）+ 目标帧宽 + 帧率（1~30，默认 12） |
| 输出 | 横向精灵图（PNG，保留透明通道）+ `{ frames, fps }` |
| 边界 | 帧尺寸不一致时按第一帧统一缩放（contain 居中，透明填充） |
| 异常 | 单帧解码失败：跳过并提示跳过的文件名；全部失败则中止 |
| 验收 | 8 张 200×200 PNG 合成 8 帧精灵图，气泡内 12fps 循环 |

### FEAT-106 九宫格切片编辑

| 项 | 规格 |
|----|------|
| 适用范围 | **静态图片素材**（PNG/JPG/WebP/SVG）；动态图片与精灵图不切片（整层绘制 + 圆角裁剪），向导本步自动切换形态 |
| 输入 | 四向切片内缩量（左/上/右/下，px，0~min(宽,高)/2） |
| 输出 | `slice` 几何 + 自动推导的内容内边距（可手动覆盖） |
| 交互 | 图片上 4 条可拖拽参考线 + 数值输入；实时三档长度预览（短/中/长） |
| 边界 | 切片和不得超过素材尺寸；0 = 该方向不切片（整段拉伸） |
| 异常 | 越界输入被夹取；素材尺寸小于切片和时提示并回落 |
| 验收 | 拖动左切片线时预览气泡左端形状固定、中段拉伸；三档预览均无变形/渗色 |

### FEAT-107 皮肤保存/命名/应用/删除

| 项 | 规格 |
|----|------|
| 输入 | 名称（1~40 字符，默认「皮肤 yyyy-MM-dd HH:mm」）、应用目标（助手/用户/两者） |
| 输出 | 皮肤记录入库 + 对应侧 `focusBubbleSkin` 写入皮肤 id |
| 列表 | 皮肤库网格：缩略图（取素材首帧）、名称、类型徽标（静态/动画/精灵）、应用目标标记 |
| 操作 | 应用 / 重命名 / 删除（删除时若正被某侧引用，清空该侧引用并提示） |
| 边界 | 同名允许（id 唯一）；内置皮肤只读（不可改名/删除） |
| 异常 | 保存失败（宿主不可用）：提示且不写入设置；删除失败：恢复列表原状 |
| 验收 | 保存后列表出现该皮肤；点「应用到助手」后对话中助手气泡立即换肤；删除后气泡回落默认样式 |

### FEAT-108 皮肤渲染

| 项 | 规格 |
|----|------|
| 输入 | 皮肤记录（kind/slice/padding/radius/frames/fps/fit）+ 素材字节 URL |
| 输出 | 静态图皮肤：`border-image` 九宫格（区域裁剪 + 拉伸）；动画图皮肤：整层 `background-size: cover\|100% 100%`（原生动画）；精灵皮肤：帧步进动画；动态/精灵按 `radius` 圆角裁剪 |
| 优先级 | 皮肤 > 背景图片 > 渐变 > 背景色（皮肤激活时前者不参与渲染） |
| 边界 | 皮肤素材 404/解码失败 → 回落到无皮肤样式并输出一次控制台告警 |
| 异常 | 精灵帧数 1 视为静态图；fps ≤ 0 按 12fps |
| 验收 | 应用静态皮肤后长文本气泡两端不拉伸变形；动画/精灵皮肤按设定帧率循环且圆角裁剪正确 |

### FEAT-109 皮肤资产宿主持久化

| 项 | 规格 |
|----|------|
| 输入 | 皮肤元数据 + 素材字节（base64） |
| 输出 | `~/.dsh/chat-focus/skins/index.json` + `skins/<id>.bin`；素材经 `GET /api/chat-focus/skin-asset?id=&v=` 提供 |
| 鉴权 | 复用宿主 `/api` 信任栅栏 + 浏览器会话认证（不新增鉴权面） |
| 边界 | 单皮肤素材 ≤ 8MB；index.json ≤ 256KB（超出拒绝并提示） |
| 异常 | 目录不可写 / 磁盘错误：RPC 返回结构化失败，客户端提示且不改变本地状态 |
| 验收 | 保存皮肤后重启 dsh，皮肤仍在；换浏览器打开同一 dsh，皮肤可用 |

### FEAT-110 设置页左标签栏与语义重组

| 项 | 规格 |
|----|------|
| 输入 | 用户点击左侧标签栏 |
| 输出 | 基础 / 折叠 / 气泡外观 / 皮肤 / 高级 五页；宽屏左栏 + 中表单 + 右侧常驻预览，窄屏（< 860px）导航转横向、预览可折叠 |
| 语义 | 「模板」=内置配色快速套用；「皮肤」=图片/动态素材；「遮罩」=文字可读性；「底纹不透明度」=整层透明 |
| 边界 | 皮肤激活时，该侧「背景」小节控件禁用并显示「已由皮肤接管」；标签状态为组件私有，不持久化（重开设置回到「基础」） |
| 异常 | 宿主未提供 `connection` 时，皮肤页与高级页显示不可用说明，其余页正常工作 |
| 验收 | 五页切换流畅（含键盘方向键）；皮肤激活后背景控件变灰且有说明；窄屏下预览可折叠且表单可滚动 |

### FEAT-111 运行时视频皮肤图层

| 项 | 规格 |
|----|------|
| 输入 | 制作器选择「直接使用视频」的 MP4 / WebM（≤ 8MB），或已有 `kind='video'` 皮肤记录 |
| 输出 | 气泡底纹层内的静音循环 `<video>`：`object-fit` 由 fit（覆盖/拉伸）决定，圆角裁剪，不接收指针事件 |
| 边界 | 仅在气泡进入视口（含 120px 余量）时播放，离开视口立即暂停；`prefers-reduced-motion` 下只显示首帧；单帧视频等同静态图 |
| 异常 | 素材 404 / 解码失败 → 底纹层空置，文字仍可读，控制台一次告警；不支持 `IntersectionObserver` 时退化为持续播放 |
| 验收 | 应用视频皮肤后气泡内循环播放且无控制条；滚动离开视口后 `video.paused === true`；资产请求返回 206 且可 seek |

### FEAT-112 气泡设置批量操作

| 项 | 规格 |
|----|------|
| 输入 | 「复制到另一侧」按钮；「恢复全部默认设置」按钮 + 二次确认 |
| 输出 | 复制：本侧 19 个字段（含皮肤 id）写入另一侧；重置：全部 `focus*` 字段回到默认值 |
| 边界 | 两次操作都经**一次**设置原子写入（`SettingsScope.mutate`），失败时保留原值并回滚本地镜像 |
| 异常 | 无变化时不写（避免无谓的 revision 抖动） |
| 验收 | 复制后另一侧视觉与源侧一致；重置后气泡、折叠、皮肤全部回到初始状态；设置文件只发生一次 revision 变更 |

## 5. 非功能约束

| 类别 | 约束 |
|------|------|
| 性能 | 单气泡新增 DOM ≤ 2 个节点；100 气泡会话首屏渲染增量 < 30ms；抽帧期间主线程单次阻塞 < 50ms |
| 体积 | 客户端 bundle 增量 ≤ 120KB（未压缩）；新增运行时依赖 0 |
| 兼容 | 既有 `focusBubble*` 字段全部保留；旧设置文件零迁移 |
| 降级 | 宿主无 `connection` 服务 → 皮肤库不可用，静态内联背景图片仍可用 |
| 安全 | 皮肤素材仅由本机 `/api` 鉴权路由提供；不接受远端 URL 作为皮肤源 |
